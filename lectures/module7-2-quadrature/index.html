function vander_legendre(x, k=nothing)
    if isnothing(k)
        k = length(x) # Square by default
    end
    m = length(x)
    Q = ones(m, k)
    Q[:, 2] = x
    for n in 1:k-2
        Q[:, n+2] = ((2*n + 1) * x .* Q[:, n+1] - n * Q[:, n]) / (n + 1)
    end
    Q
end

Recap Extrapolation derivation¶

The trapezoid rule with nnn points has an interval spacing of h=1/(n−1)h = 1/(n-1)h=1/(n−1). Let IhI_hIh​ be the value of the integral approximated using an interval hhh. We have numerical evidence that the leading error term is O(h2)O(h^2)O(h2), i.e.,

Ih−I0=ch2+O(h3)I_h - I_0 = c h^2 + O(h^3)Ih​−I0​=ch2+O(h3)
(2)

for some as-yet unknown constant ccc that will depend on the function being integrated and the domain of integration.

If we can determine ccc from two approximations, say IhI_hIh​ and I2hI_{2h}I2h​, then we can extrapolate to h=0h=0h=0.

For sufficiently small hhh, we can neglect O(h3)O(h^3)O(h3) and write

Ih−I0=ch2I2h−I0=c(2h)2.\begin{split} I_h - I_0 &= c h^2 \\ I_{2h} - I_0 &= c (2h)^2 . \end{split}Ih​−I0​I2h​−I0​​=ch2=c(2h)2.​
(3)

Subtracting these two lines, we have

Ih−I2h=c(h2−4h2)I_{h} - I_{2h} = c (h^2 - 4 h^2)Ih​−I2h​=c(h2−4h2)
(4)

which can be solved for ccc as

c=Ih−I2hh2−4h2.c = \frac{I_{h} - I_{2h}}{h^2 - 4 h^2} .c=h2−4h2Ih​−I2h​​.
(5)

Substituting back into the first equation, we solve for I0I_0I0​ as

I0=Ih−ch2=Ih+Ih−I2h4−1.I_0 = I_h - c h^2 = I_h + \frac{I_{h} - I_{2h}}{4 - 1} .I0​=Ih​−ch2=Ih​+4−1Ih​−I2h​​.
(6)

This is called Richardson extrapolation.

Extrapolation code¶

function fint_richardson(f, a, b; n=20)
    n = div(n, 2) * 2 + 1
    h = (b - a) / (n - 1)
    x = LinRange(a, b, n)
    fx = f.(x)
    fx[[1, end]] /= 2
    I_h = sum(fx) * h
    I_2h = sum(fx[1:2:end]) * 2h
    I_h + (I_h - I_2h) / 3
end

function quad_trapezoid(a, b; n=20)
    dx = (b - a) / (n - 1)
    x = LinRange(a, b, n)
    w = fill(dx, n)
    w[[1, end]] /= 2
    x, w

function quad_legendre(a, b; n=20)
    x = CosRange(-1, 1, n)
    P = vander_legendre(x)
    x_ab = (a+b)/2 .+ (b-a)/2*x
    w = (b - a) * inv(P)[1,:]
    x_ab, w
end

function fint_legendre(f, a, b; n=20)
    x, w = quad_legendre(a, b, n=n)
    w' * f.(x)
end

How does this work?¶

Suppose a polynomial P(x)P(x)P(x) on the interval [−1,1][-1,1][−1,1] can be written as

P(x)=Pn(x)q(x)+r(x)P(x) = P_n(x) q(x) + r(x)P(x)=Pn​(x)q(x)+r(x)
(9)

where Pn(x)P_n(x)Pn​(x) is the nnn th Legendre polnomials and both q(x)q(x)q(x) and r(x)r(x)r(x) are polynomials of maximum degree n−1n-1n−1. We know we can write this form by using long division of polynomials.

  • Why is ∫−11Pn(x)q(x)=0\int_{-1}^1 P_n(x) q(x) = 0∫−11​Pn​(x)q(x)=0?

    • Since Gaussian quadrature is exact on the polynomial r(x)r(x)r(x), since it is just integration of the interpolating polynomial of degree n−1n-1n−1, which is identical to r(x)r(x)r(x).

  • Can every polynomials of degree 2n−12n-12n−1 be written in the above form?

    • Yes, by long division of polynomials.

  • How many roots does Pn(x)P_n(x)Pn​(x) have on the interval?

    • nnn complex-valued, considering their multiplicity (Fundamental Theorem of Algebra: every non-zero, single-variable, degree nnn polynomial with complex coefficients has, counted with multiplicity, exactly nnn complex roots.).

  • Can we choose points {xi}\{x_i\}{xi​} such that the first term is 0?

    • At the roots xix_ixi​ of the nnn-th Legendre polynomial, P(xi)=r(xi)P(x_i) = r(x_i)P(xi​)=r(xi​), since Pn(xi)=0P_n (x_i ) = 0Pn​(xi​)=0 for all iii.

If Pn(xi)=0P_n(x_i) = 0Pn​(xi​)=0 for each xix_ixi​, then we need only integrate r(x)r(x)r(x), which is done exactly by integrating its interpolating polynomial. How do we find these roots xix_ixi​?

3. Gauss-Legendre quadrature¶

  1. Solve for the points, compute the weights

  • Use a Newton solver to find the roots. You can use the recurrence to write a recurrence for the derivatives.

  • Create a Vandermonde matrix and extract the first row of the inverse or (using more structure) the derivatives at the quadrature points.

  1. Use duality of polynomial roots and matrix eigenvalues.

  • A fascinating mathematical voyage; something you might see more in a graduate linear algebra class.

To approximate integrals on a general interval [a,b][a,b][a,b], the problem needs to be translated to [−1,1][-1,1][−1,1] with a simple change of variables. Using the substitution t=(2x−a−b)/(b−a)t = (2x - a - b) / (b-a)t=(2x−a−b)/(b−a), we find

function fint_gauss(f, a, b; n=4)
    """Gauss-Legendre integration using Golub-Welsch algorithm"""
    beta = @. .5 / sqrt(1 - (2 * (1:n-1))^(-2))
    T = diagm(-1 => beta, 1 => beta)
    D, V = eigen(T)
    w = V[1,:].^2 * (b-a)
    x = (a+b)/2 .+ (b-a)/2 * D
    w' * f.(x)
end

Spectral Element Method (SEM)¶

Gauss-Lobatto nodes are preferred in the quadrature formulae for the Spectral Element Method (SEM)-a high-order version of the Finite Element Method (FEM) defined on non-uniform points-, which achieves “spectral” or “exponential” convergence for the solution of Partial Differential Equations.

In finite element formulations, the weak form of a Partial Differential Equation (PDE) is evaluated on a subdomain Ωe\Omega_eΩe​ (element) and the local results are composed into a larger system of equations that models the entire problem on the global domain Ω\OmegaΩ. The weak-form involves the L2L^2L2 inner product (integral) of a variational formulation with suitable basis functions and trial/test functions (Galerkin formulation).

In Continuous Galerkin (CG) formulations, Gauss-Lobatto nodes are preferred because they include nodes at the endpoints -1 and 1, hence ensuring continuity of the basis functions across element boundaries.
