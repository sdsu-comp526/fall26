1. Condition Number of a Matrix¶

We may have informally referred to a matrix as “ill-conditioned” when the columns are nearly linearly dependent, but let’s make this concept more precise. Recall the definition of (relative) condition number:

κ=max⁡δx∣δf∣/∣f∣∣δx∣/∣x∣.\kappa = \max_{\delta x} \frac{|\delta f| / |f|}{|\delta x| / |x|} .κ=δxmax​∣δx∣/∣x∣∣δf∣/∣f∣​.
(1)

We understood this definition for scalar problems, but it also makes sense when the inputs and/or outputs are vectors (or matrices, etc.) and absolute value is replaced by vector (or matrix) norms. Consider matrix-vector multiplication, for which f(x)=Axf(x) = A xf(x)=Ax.

κ(A)=max⁡δx∥A(x+δx)−Ax∥/∥Ax∥∥δx∥/∥x∥=max⁡δx∥Aδx∥∥δx∥ ∥x∥∥Ax∥=∥A∥∥x∥∥Ax∥.\kappa(A) = \max_{\delta x} \frac{\lVert A (x+\delta x) - A x \rVert/\lVert A x \rVert}{\lVert \delta x\rVert/\lVert x \rVert} = \max_{\delta x} \frac{\lVert A \delta x \rVert}{\lVert \delta x \rVert} \, \frac{\lVert x \rVert}{\lVert A x \rVert} = \lVert A \rVert \frac{\lVert x \rVert}{\lVert A x \rVert} .κ(A)=δxmax​∥δx∥/∥x∥∥A(x+δx)−Ax∥/∥Ax∥​=δxmax​∥δx∥∥Aδx∥​∥Ax∥∥x∥​=∥A∥∥Ax∥∥x∥​.
(2)

There are two problems here:

  • I wrote κ(A)\kappa(A)κ(A) but my formula depends on xxx.

  • What is that ∥A∥\lVert A \rVert∥A∥ beastie?

Matrix norms induced by vector norms¶

Vector norms are built into the linear space (and defined in term of the inner product). Matrix norms are induced by vector norms, according to

∥A∥=max⁡x≠0∥Ax∥∥x∥.\lVert A \rVert = \max_{x \ne 0} \frac{\lVert A x \rVert}{\lVert x \rVert} .∥A∥=x=0max​∥x∥∥Ax∥​.
(3)

  • This equation also makes sense for non-square matrices -- the vector norms of the input and output spaces may differ.

  • Due to linearity, all that matters is the direction of xxx, so it could equivalently be written as

∥A∥=max⁡∥x∥=1∥Ax∥.\lVert A \rVert = \max_{\lVert x \rVert = 1} \lVert A x \rVert .∥A∥=∥x∥=1max​∥Ax∥.
(4)

The formula makes sense, but still depends on xxx.¶

κ(A)=∥A∥∥x∥∥Ax∥\kappa(A) = \lVert A \rVert \frac{\lVert x \rVert}{\lVert Ax \rVert}κ(A)=∥A∥∥Ax∥∥x∥​
(5)

Consider the matrix

A=[1000].A = \begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix} .A=[10​00​].
(6)

  • What is the norm of this matrix?

  • What is the condition number when x=[1,0]Tx = [1,0]^Tx=[1,0]T?

  • What is the condition number when x=[0,1]Tx = [0,1]^Tx=[0,1]T?

Condition number of the matrix¶

The condition number of matrix-vector multiplication depends on the vector. The condition number of the matrix is the worst case (maximum) of the condition number for any vector, i.e.,

κ(A)=max⁡x≠0∥A∥∥x∥∥Ax∥.\kappa(A) = \max_{x \ne 0} \lVert A \rVert \frac{\lVert x \rVert}{\lVert A x \rVert} .κ(A)=x=0max​∥A∥∥Ax∥∥x∥​.
(7)

If AAA is invertible, then we can rephrase as

κ(A)=max⁡x≠0∥A∥∥A−1(Ax)∥∥Ax∥=max⁡Ax≠0∥A∥∥A−1(Ax)∥∥Ax∥=∥A∥∥A−1∥.\kappa(A) = \max_{x \ne 0} \lVert A \rVert \frac{\lVert A^{-1} (A x) \rVert}{\lVert A x \rVert} = \max_{A x \ne 0} \lVert A \rVert \frac{\lVert A^{-1} (A x) \rVert}{\lVert A x \rVert} = \lVert A \rVert \lVert A^{-1} \rVert .κ(A)=x=0max​∥A∥∥Ax∥∥A−1(Ax)∥​=Ax=0max​∥A∥∥Ax∥∥A−1(Ax)∥​=∥A∥∥A−1∥.
(8)

Evidently multiplying by a matrix is just as ill-conditioned of an operation as solving a linear system using that matrix.

2. Least squares and the normal equations¶

A least squares problem takes the form: given an m×nm\times nm×n matrix AAA (m≥nm \ge nm≥n), find xxx such that

∥Ax−b∥\lVert Ax - b \rVert∥Ax−b∥
(9)

is minimized. If AAA is square and full rank, then this minimizer will satisfy Ax−b=0A x - b = 0Ax−b=0, but that is not the case in general for non-square or rank deficient matrices because bbb is not in the range of AAA. The residual Ax−bA x - bAx−b must be orthogonal to the range of AAA.

So if bbb is in the range of AAA, we can solve Ax=bA x = bAx=b. If not, we need only to orthogonally project bbb into the range of AAA.

Solution by QR (Householder triangulation)¶

Solves Rx=QTbR x = Q^T bRx=QTb.

This method is stable and accurate.

Solution by Cholesky¶

The mathematically equivalent form (ATA)x=ATb(A^T A) x = A^T b(ATA)x=ATb are called the normal equations. The solution process involves factoring the symmetric and positive definite n×nn\times nn×n matrix ATAA^T AATA.

The product ATAA^T AATA is ill-conditioned: κ(ATA)=κ(A)2\kappa(A^T A) = \kappa(A)^2κ(ATA)=κ(A)2 and can reduce the accuracy of a least squares solution.

Solution by Singular Value Decomposition¶

Next, we will discuss a factorization

UΣVT=AU \Sigma V^T = AUΣVT=A
(10)

where UUU and VVV have orthonormal columns and Σ\SigmaΣ is diagonal with nonnegative entries. The entries of Σ\SigmaΣ are called singular values and this decomposition is the singular value decomposition (SVD).

Singular values of a linear operator (matrix AAA) are the square roots of the (necessarily non-negative) eigenvalues of the self-adjoint operator A∗AA^{*}AA∗A (where A∗A^{*}A∗ denotes the adjoint of AAA.)

It may remind you of an eigenvalue decomposition XΛX−1=AX \Lambda X^{-1} = AXΛX−1=A, but

  • the SVD exists for all matrices (including non-square and deficient matrices)

  • U,VU,VU,V have orthogonal columns (while XXX can be arbitrarily ill-conditioned).

  • Indeed, if a matrix is symmetric and positive definite (all positive eigenvalues), then U=VU=VU=V and Σ=Λ\Sigma = \LambdaΣ=Λ. Computing an SVD requires a somewhat complicated iterative algorithm, but a crude estimate of the cost is 2mn2+11n32 m n^2 + 11 n^32mn2+11n3. Note that this is similar to the cost of QRQRQR when m≫nm \gg nm≫n, but much more expensive for square matrices.

4. Geometry of the Singular Value Decomposition¶

default(aspect_ratio=:equal)

function peanut()
    theta = LinRange(0, 2*pi, 50)
    r = 1 .+ .4*sin.(3*theta) + .6*sin.(2*theta)
    r' .* [cos.(theta) sin.(theta)]'
end

function circle()
    theta = LinRange(0, 2*pi, 50)
    [cos.(theta) sin.(theta)]'
end

function Aplot(A)
    "Plot a transformation from X to Y, first applied to a peanut shape and then to a circle"
    X = peanut()
    Y = A * X
    p = scatter(X[1,:], X[2,:], label="in")
    scatter!(p, Y[1,:], Y[2,:], label="out")
    X = circle()
    Y = A * X
    q = scatter(X[1,:], X[2,:], label="in")
    scatter!(q, Y[1,:], Y[2,:], label="out")
    plot(p, q, layout=2)
end

Givens Rotation (as example of orthogonal matrix)¶

We can rotate the input using a 2×22\times 22×2 matrix, parametrized by θ\thetaθ. Its transpose rotates in the opposite direction.

function givens(theta)
    s = sin(theta)
    c = cos(theta)
    [c -s; s c]
end

Reflections¶

We’ve previously seen that reflectors have the form F=I−2vvTF = I - 2 v v^TF=I−2vvT where vvv is a normalized vector. Reflectors satisfy FTF=IF^T F = IFTF=I and F=FTF = F^TF=FT, thus F2=IF^2 = IF2=I (i.e., it is an idempotent matrix).

function reflect(theta)
    v = [cos(theta), sin(theta)]
    I - 2 * v * v'
end

Singular Value Decomposition¶

The SVD is A=UΣVTA = U \Sigma V^TA=UΣVT where UUU and VVV have orthonormal columns and Σ\SigmaΣ is diagonal with nonnegative entries. It exists for any matrix (non-square, singular, etc.). If we think of orthogonal matrices as reflections/rotations, this says any matrix can be represented by the sequence of operations: reflect/rotate, diagonally scale, and reflect/rotate again.

Let’s try a random symmetric matrix.

A = randn(2, 2)

@show det(A) # Positive means orientation is preserved
