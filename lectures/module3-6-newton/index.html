function bisect_iter(f, a, b, tol)
    hist = Float64[]
    while abs(b - a) > tol
        mid = (a + b) / 2
        push!(hist, mid)
        if hasroot(f, a, mid)
            b = mid
        else
            a = mid
        end
    end
    hist
end

1. Newton-Raphson Method¶

Much of numerical analysis reduces to Taylor series, the approximation

f(x)=f(x0)+f′(x0)(x−x0)+f′′(x0)(x−x0)2/2+⋯⏟O((x−x0)3)f(x) = f(x_0) + f'(x_0) (x-x_0) + f''(x_0) (x - x_0)^2 / 2 + \underbrace{\dotsb}_{O((x-x_0)^3)}f(x)=f(x0​)+f′(x0​)(x−x0​)+f′′(x0​)(x−x0​)2/2+O((x−x0​)3)⋯​​
(4)

centered on some reference point x0x_0x0​.

In numerical computation, it is exceedingly rare to look beyond the first-order approximation

f~x0(x)=f(x0)+f′(x0)(x−x0).\tilde f_{x_0}(x) = f(x_0) + f'(x_0)(x - x_0) .f~​x0​​(x)=f(x0​)+f′(x0​)(x−x0​).
(5)

Since f~x0(x)\tilde f_{x_0}(x)f~​x0​​(x) is a linear function, we can explicitly compute the unique solution of f~x0(x)=0\tilde f_{x_0}(x) = 0f~​x0​​(x)=0 as

x=x0−f(x0)f′(x0).x = x_0 - \frac{f(x_0)}{f'(x_0)} .x=x0​−f′(x0​)f(x0​)​.
(6)

This is Newton’s Method (aka Newton-Raphson or Newton-Raphson-Simpson) for finding the roots of differentiable functions.

1.1 An implementation¶

function newton(f, fp, x0; tol=1e-8, verbose=false)
    x = x0
    for k in 1:100 # max number of iterations
        fx = f(x)
        fpx = fp(x)
        if verbose
            println("iteration $k: x=$x,  f(x)=$fx,  f'(x)=$fpx")
        end
        if abs(fx) < tol
            return x, fx, k
        end
        x = x - fx / fpx
    end
end

Consider the iteration

where ggg is a continuously differentiable function. Suppose that there exists a fixed point x∗=g(x∗)x_* = g(x_*)x∗​=g(x∗​). By the mean value theorem, we have that

xk+1−x∗=g(xk)−g(x∗)=g′(ck)(xk−x∗)x_{k+1} - x_* = g(x_k) - g(x_*) = g'(c_k) (x_k - x_*)xk+1​−x∗​=g(xk​)−g(x∗​)=g′(ck​)(xk​−x∗​)
(9)

for some ckc_kck​ between xkx_kxk​ and x∗x_*x∗​.

Taking absolute values,

∣ek+1∣=∣g′(ck)∣∣ek∣,|e_{k+1}| = |g'(c_k)| |e_k|,∣ek+1​∣=∣g′(ck​)∣∣ek​∣,

xk+1=g(xk)x_{k+1} = g(x_k)xk+1​=g(xk​)

g(xk)=g(x∗)+g′(x∗)(xk−x∗)+O((xk−x∗)2)g(x_k) = g(x_*) + g'(x_*)(x_k - x_*) + O((x_k-x_*)^2)g(xk​)=g(x∗​)+g′(x∗​)(xk​−x∗​)+O((xk​−x∗​)2)

Rootfinding summary and outlook¶

  • Newton methods are immensely successful

    • Convergence theory is local; we need good initial guesses

    • Computing the derivative f′(x)f'(x)f′(x) is intrusive (and can be error-prone)

      • Avoided by secant methods (approximate the derivative)

      • Algorithmic or numerical differentiation can also be used instead of computing the derivative by hand

    • Bisection is robust when conditions are met
